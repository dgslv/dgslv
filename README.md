### Hi, I'm Diego 👋

Data & AI engineer from Brazil. I build the parts of a data product that have to work every day: pipelines, scoring models, FastAPI services, React dashboards, and the CI/CD and observability that keep them alive in production.

Currently lead engineer at [RapidCanvas](https://rapidcanvas.ai), delivering AI-powered lead-scoring and analytics products end to end for enterprise customers.

---

#### What I do

- **Own products end to end.** From the SQL schema and the scoring logic to the React frontend, the deploy pipeline, and the on-call fix when it breaks at 2am.
- **Make data trustworthy.** Audited migrations, SCD2 repairs, transactional reloads, and LLM validators that record every correction they make.
- **Build tools the team actually adopts.** A kubectl-style CLI that became the standard deploy path, a read-only SQL web IDE for customer databases, shared service libraries reused across every engagement.
- **Keep AI-assisted engineering cheap.** I run a Claude Code setup with a schema'd knowledge base, transcript miners, and cost rules, so the assistant accumulates knowledge instead of rediscovering it every session.
